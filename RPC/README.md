## 🧠 How the Game Works

1. Player selects **Rock, Paper, or Scissors**
2. Computer randomly selects an option
3. Choices are compared using predefined rules:
   - Rock beats Scissors
   - Scissors beats Paper
   - Paper beats Rock
4. Result is displayed instantly:
   - **You Win 🎉**
   - **You Lose ❌**
   - **It's a Draw 🤝**
