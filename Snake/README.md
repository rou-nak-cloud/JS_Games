# 🐍 Anaconda – Snake Game

**Anaconda** is a modern, responsive Snake game built using **HTML, CSS, and Vanilla JavaScript**.  
It features smooth movement, keyboard & on-screen controls, score tracking, high score persistence, and a clean game-over modal.

---
## 🌐 Live Demo

👉 **Play the game here:**  
🔗 https://js-snakegame-six.vercel.app/

---

## 🎮 Gameplay Preview

- Control the snake using **Arrow Keys** or **On-Screen Buttons**
- Eat food to grow longer
- Avoid hitting walls or your own body
- Beat your **High Score**, which is saved automatically

---

## 🚀 Features

- 🐍 Classic Snake mechanics
- 🎯 Food generation with growth logic
- 💥 Self-collision & wall-collision detection
- 🧠 Direction reverse prevention
- 📊 Score & High Score system (LocalStorage)
- 🪟 Custom Game Over Modal (no alerts)
- 📱 Responsive layout (desktop & mobile)
- ⚡ Smooth grid-based movement

---

## 🛠️ Tech Stack

- **HTML5**
- **CSS3** (Grid + Flexbox)
- **JavaScript (ES6+)**
- **LocalStorage API**
