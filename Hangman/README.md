# 🎯 Hangman – Word Guessing Game

**Hangman** is a fun and interactive **word guessing game** built using **HTML, CSS, and Vanilla JavaScript**.  
Players must guess the hidden word letter by letter before the hangman is fully drawn.

## 🌐 Live Demo

👉 **Play the game here:**

---

## 🎮 Gameplay Overview

- Guess letters using the **on-screen keyboard**
- Correct guesses reveal letters in the word
- Wrong guesses draw the hangman step by step
- The game ends when:
  - ✅ The word is guessed correctly
  - ❌ Maximum wrong guesses are reached

---

## 🚀 Features

- 🔤 Random word & hint generation
- ❌ Wrong guess counter with visual feedback
- 🖼️ Progressive hangman illustration
- 🪟 Game Over & Win modal
- 🎨 Clean and responsive UI
- 📱 Mobile-friendly design
- ⚡ Smooth animations & transitions

---

## 🧠 How the Game Works

- A random word and hint are selected from a predefined list
- Each guessed letter is checked against the word
- Correct guesses reveal letter positions
- Incorrect guesses:
  - Increase the wrong guess count
  - Update the hangman image
- The game disables already used letters to prevent reuse

---

## 🎯 Game Rules

- Maximum wrong guesses: **Limited**
- Letters can be used only once
- The player wins by revealing all letters
- The player loses when the hangman is completed
