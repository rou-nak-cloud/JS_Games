# 🧠 Memory Card Game (v1)

A fun and interactive **Memory Card Matching Game** built using **HTML, CSS, and Vanilla JavaScript**.  
Flip the cards, match identical pairs, and test your memory skills!

---

## 🚀 Features (v1)

- 🎴 Flip card animation
- 🧠 Memory-based matching logic
- 🔒 Deck locking while cards are being compared
- ❌ Shake animation for wrong matches
- ✅ Matched cards stay flipped
- 🎉 Win alert when all pairs are matched
- 🔁 Automatic game reset after completion

---

## 🛠️ Tech Stack

- **HTML5** – Structure  
- **CSS3** – Styling & animations  
- **JavaScript (ES6)** – Game logic  

---

## 📸 Gameplay Preview

- Click on a card to flip it  
- Match two identical cards  
- Wrong match → cards shake & flip back  
- Correct match → cards stay revealed  
- Match all pairs to win the game  

---

## 🧩 Game Logic Overview

- Tracks two selected cards at a time
- Prevents extra clicks using a deck lock
- Uses image `src` comparison for matching
- Keeps count of matched pairs
- Resets game state cleanly after completion
