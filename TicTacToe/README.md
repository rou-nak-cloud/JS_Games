# ❌⭕ Tic Tac Toe Game

A classic **Tic Tac Toe** game built using **HTML, CSS, and Vanilla JavaScript**.  
Play as **X or O**, take turns, and try to get three in a row! Against the computer!

---

## Live Play

[Tic Tac Toe Live](https://js-games-chi.vercel.app/)

## 🎮 Features

- 🧠 Single-player gameplay (X vs O AI)
- 🏆 Win detection (rows, columns, diagonals)
- 🤝 Draw detection
- 🔄 Restart game functionality
- 🎨 Clean and responsive UI
- ✨ Highlighted winning cells

---

## 🛠️ Tech Stack

- **HTML** – Game structure
- **CSS** – Styling and layout
- **JavaScript** – Game logic and interactivity

---

## ⚙️ How the Game Works

- The game board is represented using an array of 9 elements.
- Each click updates the board and checks:
  - ✅ Winning combinations
  - 🤝 Draw condition
- Once the game ends:
  - Winning cells are highlighted
  - Restart button becomes visible
